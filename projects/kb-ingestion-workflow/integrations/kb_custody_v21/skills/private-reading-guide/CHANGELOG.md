# Changelog

## 2026-09-30 · V2.1 integration baseline

Major changes from the earlier book-only skill:

- Expanded scope from books to papers, long articles, reports, policy/research materials, and chapters.
- Removed any requirement to force 3–5 themes for short material.
- Added V2.1 interface contract: SourceRecord + Authorized ExtractedSource + ReadingCoverage + CurationData + ReaderContext + StyleRules.
- Added outputs: guide_markdown, evidence_links, unresolved_issues, coverage_statement.
- Made ExtractedSource the primary textual basis; CurationData remains auxiliary.
- Added strict visual-reading rules: preserved image ≠ read image.
- Added source-first / necessary-verification behavior; ordinary ingestion does not automatically fact-check.
- Added Human Preview integration boundary.
- Added hard prose rule against empty “不是……而是……” style contrasts when no real comparison exists.
- Added rules against process residue, repeated disclaimers, dashboard-like formatting, and exaggerated interpretation of weak numbers.
- Added source-discipline and V2.1 integration references.
