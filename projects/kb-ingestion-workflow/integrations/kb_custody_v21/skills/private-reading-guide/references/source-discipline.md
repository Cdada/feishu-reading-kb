# Source Discipline Reference

## Four layers to keep separate

### 1. Source statement

What the authorized source explicitly says.

Use the source's own terminology when it matters.

### 2. Interpretation

A reading or synthesis produced from the source.

It may be useful and durable, but it is not the author's wording.

### 3. Cross-reading

A concept from another book, course, model, or discipline used to illuminate the source.

Name the origin when needed and state the limit of the analogy.

### 4. External verification

Independent checking of bibliographic identity, factual claims, numbers, dates, or historical assertions.

This is not part of ordinary guide writing unless explicitly requested or required by the workflow.

## Version discipline

A guide must describe the version actually in hand.

Examples:

- publisher/official full text;
- abridged version;
- abstract;
- excerpt;
- repost;
- translation;
- presentation;
- notes.

A successful extraction says the captured file was converted. It does not prove the captured material is the canonical full work.

## Image discipline

Keep these distinct:

- image preserved;
- image available locally;
- image visually read;
- image interpreted;
- image transcribed.

A caption can support a statement about what the caption says. It cannot support a detailed statement about unseen diagram contents.

## Evidence precision

Use the most precise locator the pipeline truly has.

Allowed examples:

- whole document;
- section;
- paragraph;
- text character range;
- page when mapped reliably;
- bbox only when actually captured.

Never fabricate a more precise locator for convenience.
