# 通用读书归档规则示例

仅整理当前明确指定的独立测试库。保留原件、来源标识、提取版本及对应导读，不覆盖正式个人库。

每篇确认入库的资料先建立来源卡片与读书摘录；按需生成可独立复用的知识卡片、主题入口和简报。沿用现有目录：10_Reading_读书摘录、20_Cards_知识卡片、30_Topics_主题索引、40_Projects_专项引用、50_Daily_Briefs_知识简报。

用相对 Markdown 链接连接来源、笔记、卡片和主题。既有卡片只在证据充分且概念确实一致时复用，不凭标题相似覆盖已有内容。没有可复用知识点时允许不生成卡片。

资料关系与主题相似不同。公众号解读与论文原文各自保留，明确标注原文；经用户确认后挂接。没有可靠关联候选时不强行匹配。
