# 知识库 V2 系统功能清单

本清单目前收录两项系统管理检查。两项均保留为按需功能，由用户在 Codex 对话中明确提出后执行；不再定时运行。查看清单本身不会执行检查，也不代表新增了飞书机器人命令。

| 功能 | 可以怎样说 | 检查什么 | 返回什么 | 执行方式 |
| --- | --- | --- | --- | --- |
| [模型变更检查](manual-model-check.md) | “检查读书简报的模型变更” | 实际配置、最近运行的模型字段，以及官方发布、别名变化和弃用说明 | 是否有需要调整的变化、影响、可选方案和无法确认项 | 按需、只读；更换模型须另行确认 |
| [知识库离线回归检查](manual-offline-regression.md) | “执行知识库离线回归检查” | 已登记资料及部署配置的变化、冻结题包完整性、来源摘要与依赖是否一致 | 本次检查或复用的范围、通过/待复核/失败数量、资料变化与报告位置 | 按需；读取资料，只写本地检查记录；不调用业务模型 |

可以说“显示知识库 V2 系统功能清单”查看本页；明确要求“两项都检查”时执行上述两项。每次只执行本次请求的范围，不顺带更换模型、修订题目或启动其他功能。

## 共同规则

- 日常归档服务和阅读简报投送独立运行；停用这两项检查的定时调度不改变日常业务安排。
- 管理检查不调用业务模型或发起付费 API 验收。Codex 执行对话本身仍会使用订阅额度，不能把“0业务模型调用”解释成完全不消耗额度。
- 不改知识库正文、参考答案、模型、凭据、备份或服务启停；需要修改时说明发现和建议，再按用户明确授权处理。
- 每次手动检查都简短回复实际范围和结果，包括无变化、缓存复用或无法完成。保留历史记录，不清零账本或工时。
- AI回答生成与质量评分是另一项工作，目前仍需评分校准及独立的有限评测授权；本清单中的离线检查不授予这类调用。
- 将来只有用户明确要求恢复定时检查时，才重新启用相应调度。真实路径、绑定及既有验收记录只留本地。
