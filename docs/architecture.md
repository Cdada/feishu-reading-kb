# 结构与边界

| 位置 | 职责 |
| --- | --- |
| `projects/kb-ingestion-workflow/scripts/` | 转换与原件/正文处理工具 |
| `projects/kb-ingestion-workflow/integrations/kb_custody_v21/` | 来源登记、原件保管、任务状态、导读、确认、整理、关联、存储与备份 |
| `projects/deepseek-harness-feishu-bridge/feishu-gateway/` | 飞书消息与卡片、模型适配及历史网关集成 |
| `projects/kb-ingestion-workflow/integrations/local_conversion_mcp/` | 本地转换 MCP（模型上下文协议）接口 |
| `scripts/check_public_source.py` | 公开提交的文件与历史检查 |

关键状态持久化在本机。输入身份、原件摘要、转换版本、预览版本和用户确认共同约束后续操作；更新资料或规则不会自动继承旧确认。AI 整理与独立复核是不同步骤，独立复核仍由模型执行，不等于人工保证正确。

论文页眉页脚处理保留版面与重复性证据；不把区域位置作为删除一切脚注的依据。原件保留供复查。关联保存明确关系与双向入口，无匹配时正常结束，不要求每篇资料都有版本关系。

存储工具核对目标身份；备份覆盖受管理原件、整理成果及关联历史。恢复先校验再写入新目录，不覆盖现存库、不启动服务、不重放任务。仓库含云盘适配与合成测试，默认配置关闭真实同步。具体真实磁盘操作需要独立执行计划。

本仓库公开的是源码、合成测试和通用说明。早期试验入口仍保留在目录中，不代表全部已组成开箱即用的生产安装器；以离线开发入口和当前测试工作流为可复现起点。
