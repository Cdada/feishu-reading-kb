# 知识库离线回归：手动检查

入口见[系统功能清单](system-functions.md)。用户明确要求“执行知识库离线回归检查”后，运行已部署入口一次，不启动持续监测，也不恢复每日或每周定时任务。

## 执行步骤

1. 读取 `.dev-runtime/kb-v21/manual-offline-regression.local.md` 中的本机绑定，确认指定资料、已有部署入口和结果目录。缺少绑定时明确说明，不能猜测其他知识库或扫描整个磁盘。
2. 只运行该本机说明指定的入口，保留结构化结果；必要时读取结果指向的本地报告。入口会核验其冻结配置、重新观察已登记资料并根据实际变更及周期安排相应离线检查。
3. `state=unchanged` 表示本次观察无变化、未重新执行题目检查；明确引用上次报告和时间，不能说刚刚重新跑完全部题目。周期到期只在此次手动执行中参与规划，不会自行唤醒程序。
4. 新完成报告分别列出真实来源、合成材料、通过/待复核/失败数量及未覆盖范围；保留题默认排除。读取原文摘要或题包完整性通过，不代表检索充分性或AI回答质量通过。
5. 缺盘、配置变化或执行失败应报告无法完成；不能借用旧成功结果宣称本次通过。保留原记录，不重置状态或伪造时钟来强制重跑。要求额外全量重跑时先明确当前入口的能力与本次范围。

## 边界与输出

检查只读知识库及冻结题包，只在既有本地状态目录保存结果，不改正文、题目或参考答案，不调用业务模型、执行语义候选、扩大评测预算、启动/停止归档服务或旧V1、迁移资料或修改备份。原有历史结果及累计账本保持不变。

手动请求完成后回复实际范围、结果、新执行/复用状态及本地报告链接。没有变化也给出简短结果；不向飞书、熊掌记阅读正文或其他人发送通知，不上传私人材料或报告。
